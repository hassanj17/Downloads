# Sleep Log Tracker

## About the Project
Our project is a Sleep Log Tracker made using Python. It lets users enter how many hours they slept and check their sleep information. We made this program to give users a simple way to keep track of their sleep.

## What the Program Can Do
- Add a sleep entry with a date and hours slept.
- View a summary of sleep information.
- View all sleep entries.
- Choose different options from a menu.
- Exit the program when finished.

## Project Files
- `main.py` - Shows the menu and lets the user choose an option.
- `tracker.py` - Contains the functions used to add and view sleep entries.
- `data.py` - Stores the sleep information while the program is running.
- `.github/issue_tracking.csv` - Keeps track of our tasks and progress.

## What You Need
- Python 3
- Visual Studio Code
- Git and GitHub to work on and share the project.

## How to Run the Program
1. Download or clone the project from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Type `python main.py` and press Enter. On Windows, you can also try `py main.py`.
5. The menu will appear, and you can choose what you want to do.

## How to Use It
1. Choose option 1 to add a sleep entry.
2. Choose option 2 to view a sleep summary.
3. Choose option 3 to see all sleep entries.
4. Choose option 4 to exit the program.
